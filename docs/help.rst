Getting help
============

If you need help using BIDScoin, have questions about its behavior or features, or want to discuss a problem, please use one of the following support channels:

- `GitHub Issues <https://github.com/Donders-Institute/bidscoin/issues>`__ (tip: search open and closed issues first to see whether your question has already been answered)
- `NeuroStars <https://neurostars.org/tag/bidscoin>`__ (use the ``bidscoin`` tag and select the *Software Support* category)

You may also find the answer to your question in the `troubleshooting guide <./troubleshooting.html>`__.

If you believe you have found a bug or would like to request a new feature, please submit a `GitHub issue <https://github.com/Donders-Institute/bidscoin/issues>`__.
